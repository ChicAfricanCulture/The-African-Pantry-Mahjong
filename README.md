# The African Pantry Mahjong

A tile-matching game built from the African pantry. The tiles show ingredients and kitchen things like okra, egusi, plantain, peanuts, palm oil, Maggi and the mortar. Click a tile to learn a little about how it is used in African cooking.

**▶ Play it here: [https://chicafricanculture.github.io/The-African-Pantry-Mahjong/](https://chicafricanculture.github.io/The-African-Pantry-Mahjong/)**

A free game from [The African Gourmet](https://www.theafricangourmet.com/), made to help people learn about African food through play.

## How to play

- Pick two matching, free tiles to clear them. Only the top tiles in a stack can be picked.
- Click any tile to read about that ingredient.
- Use **Find Match** for a hint, or **Shuffle** when you're stuck.
- Clear the board to move up a level. You can also play with the keyboard: arrow keys to move, Enter or Space to select.
